Verificar cadastros

Um clique acende o selo de confirmado. O selo quer dizer uma coisa só: o responsável confirmou que os dados estão certos — não é nota nem recomendação. Só marque depois de ele responder.

A gravação acontece na planilha, não aqui. O selo aparece no site na sincronização seguinte — até uma hora, ou na hora se você rodar Actions → Sincronizar planilha do formulário → Run workflow.
